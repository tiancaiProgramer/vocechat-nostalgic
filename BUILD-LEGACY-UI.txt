VoceChat 新版底座 / 旧版界面

源码基础：haorwen/vocechat-client-flutter
基线提交：fbfa4cf85a6306bfbe9c13b67cf0aab85f8cf5ab
旧界面参考：imdingji/vocechat-android，ecb4562ca5f56329a0d3b1a75c56ea21e879c7ff
版本：0.3.33+3106
Android applicationId：com.privoce.vocechatclient.legacyui
名称：vocechat怀旧版

实现范围：新版的路由、账号存储、会话、表情/回应、RTC、Avo、画中画和后台消息；
手机及折叠屏展开时使用旧版的底部导航、灰白标题栏、服务器选择页、登录页、列表、聊天输入栏和设置入口风格。
Avo、通知和存储等新增功能从旧式设置列表进入。保留新版详细功能页。
不启用应用内更新。此包可与原版及此前适配版共存，需要单独登录，未迁移已有私有账号数据。
消息通知设置针对聊天消息通知类别；后台连接通知开关不再决定消息通知权限显示。
接听已有私聊通话复用来电房间，保留 RTC token 续期和异步回调生命周期保护。

构建环境：Flutter 3.35.7 / Dart 3.9.2，JDK 17，Android SDK 36，
NDK 27.0.12077973，Gradle 8.14.3，AGP 8.11.1。

1. flutter pub get
2. 配置 android/local.properties 的 sdk.dir 和 flutter.sdk；版本为0.3.33 / 3106。
3. 配置 android/key.properties 的 storeFile / storePassword / keyAlias / keyPassword。
   本源码包不含签名私钥、密码或本机路径配置。继续升级已安装的交付包需要相同签名。
4. flutter build apk --release --flavor standalone --target-platform android-arm64 --no-pub
5. flutter test --no-pub
6. Android 原生测试：在android目录运行 ./gradlew :app:testStandaloneDebugUnitTest

通话端到端验证需要可用的Agora配置、服务端及两端账号；自动测试不代表实际通话已验证。
Avo实时互动需要服务端支持 /api/user/avo 和 /api/voice/avo/events_ws。

剪贴板插件兼容：packages/super_native_extensions_compat 保留上游0.8.24源码和许可证，
扩展 CargoKit 的 Flutter Gradle 插件类名识别，并适配 target-platform API，使原生库正常参与构建。

3101 修复：服务器探测10秒总超时、请求取消、Referer、HTTP/证书/格式错误就地显示；
先连接成功再保存，失败恢复操作按钮；准备登录复用成功探测一次，关闭弹层后再导航。

3102：服务器列表每行增加删除按钮和确认框，支持离线移除。
删除当前服务器时解除当前账号选择，保留保存账号、令牌和聊天记录；删除失败恢复账号选择。

3103：拨出和接听直接显示可拖动小窗，仍可手动展开。
所有RTC离线原因及远端离线视频事件移除头像；服务端连续两次确认缺席时修复漏掉的离线回调。
前后台每5秒检查来电，后台通过独立高优先级“语音来电”类别显示系统通知；
点击通知进入来电人的聊天接听，不强制打开全屏。接听、挂断、回到前台、切换账号清理提示。
同一次来电拒接后不会重复弹出，来电通知30秒自动过期并在有效来电期间续期。
后台接收需启用后台消息连接和系统通知；进程被系统强制终止后不保证收到来电。

3104：实时事件按接收顺序解析，防止较旧在线快照覆盖较新的状态；
未知状态不显示离线，切换账户清除上一账户的在线状态。
设置页整理为头像、选项、账户操作三组，统一普通菜单字号和行高；
头像下二级菜单保留我的账户、存储与数据；外观和语言合并名称，关于放选项组末尾，移除服务器项。
聊天账号面板左上角加号合并添加账户和添加服务器；账户与服务器各自使用边框卡片。

3105：恢复在线状态位置与头像状态点；未知状态明确显示“状态同步中…”。
实时连接补齐与普通API一致的Referer/Origin，规范URL尾斜杠。
WebSocket不可用时兼容原版HTTP事件流，保持有序解析和断线重连；
HTTP事件流禁用压缩缓冲，支持分片UTF-8、多行data及event字段。

3106：登录使用本安装独立、持久的设备标识，避免不同设备/客户端共用flutter会话。
会话更新/切换时明确关闭旧事件流、重试任务及等待中的连接；旧异步回调不再修改新会话。
服务端状态快照不含当前用户，本人显示值由当前实时连接是否收到有效事件决定；
连接中断/重连时撤销本人的在线值，其他用户继续使用服务端快照和增量事件。
客户端修复不会自行恢复已失效的旧设备会话，需要在应用内重新登录一次。
