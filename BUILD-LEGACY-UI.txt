实现范围：新版的路由、账号存储、会话、表情/回应、RTC、Avo、画中画和后台消息；
手机及折叠屏展开时使用旧版的底部导航、灰白标题栏、服务器选择页、登录页、列表、聊天输入栏和设置入口风格。

不启用应用内更新。此包可与原版及此前适配版共存，需要单独登录，未迁移已有私有账号数据。
消息通知设置针对聊天消息通知类别；后台连接通知开关不再决定消息通知权限显示。
接听已有私聊通话复用来电房间，保留 RTC token 续期和异步回调生命周期保护。

构建环境：Flutter 3.35.7 / Dart 3.9.2，JDK 17，Android SDK 36，
NDK 27.0.12077973，Gradle 8.14.3，AGP 8.11.1。

1. flutter pub get
2. 配置 android/local.properties 的 sdk.dir 和 flutter.sdk；版本为0.3.33-r6 / 3127。
3. 配置 android/key.properties 的 storeFile / storePassword / keyAlias / keyPassword。
   本源码包不含签名私钥、密码或本机路径配置。继续升级已安装的交付包需要相同签名。
4. flutter build apk --release --flavor standalone --target-platform android-arm64 --no-pub
5. flutter test --no-pub
6. Android 原生测试：在android目录运行 ./gradlew :app:testStandaloneDebugUnitTest

后续交付使用-r2、-r3依次递增，内部构建号继续递增以便覆盖升级。版本填写和文件命名见docs/versioning.md。
