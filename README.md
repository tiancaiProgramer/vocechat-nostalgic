# vocechat怀旧版

新版 VoceChat 功能底座，保留旧版 Android 页面风格。

当前版本：**0.3.33+3119（预发布，部分真机未验证）**。Android 应用 ID：`com.privoce.vocechatclient.legacyui`。

## 安装

从 [3119预发布](https://github.com/tiancaiProgramer/vocechat-nostalgic/releases/tag/v0.3.33-3119) 下载 ARM64 APK；[发布说明](docs/releases/3119.md)列明已验证、未测试和已知问题。支持 Android 7.0 及以上版本。

此应用可与原版共存；升级已安装的怀旧版会保留应用数据。设备会话已被服务器拒绝时，需要在应用内重新登录一次。

## 3119 更新（2026-10-29，预发布）

- 聊天图片和收藏表情最长边从240缩到180，视频缩略图从280×158缩到200×113；仍可点击查看原图或视频。
- 新增实况照片预览：打开图片后识别原文件中保留的视频，默认静音播放一次，提供实况重播与声音按钮；退到后台暂停，关闭后清理提取的临时视频。
- 安卓相册优先读取原文件以保留动态部分；支持标准XMP、旧MicroVideo偏移、有效JPEG附加视频，以及HEIC/AVIF的mpvd容器。
- iPhone同名照片（JPEG/HEIC）与MOV可在文件选择器中一起选择，由用户确认合并为一张实况照片；也保留分别添加。iOS相册实况资源导入路径已接入，但本次只交付Android包。
- 延续3118的附件按钮右对齐和局域网快传。无需修改VC或Nginx。

全量Flutter回归713项通过、5项环境用例跳过；修改范围静态检查无问题。Android真机播放和HEIC/MOV导入待手机重新连接后验证。只有仍包含动态资源的原文件可播放，已被其他客户端转为静态图的历史消息不能恢复。见[实况照片说明](docs/live-photos.md)及[3119发布说明](docs/releases/3119.md)。

## 3118 更新（2026-10-29，本地开发版）

- 聊天列表顶部从服务器公开资料刷新名称；头像账户面板保留左上角加号，移除右上角关闭按钮。
- 输入框图片、文件入口合并为回形针，继续使用原图片/视频面板。面板保留文件入口与原相机点按拍照、长按录像操作。
- 面板的文件入口左侧新增“快传”，两个按钮在标题行靠右对齐；聊天页加号及账户面板加号均可进入“文件传输”。
- Android 独立版新增同局域网设备发现、接收确认、六位校验码、加密文件直传、进度、取消和完整性校验；最多一次16个文件，接收后可保存到手机。
- 快传独立于 VC 服务器上传和消息通知模式；两端需安装支持此功能的怀旧版并打开文件传输页面，连接同一局域网。

已在Android16真机与同Wi-Fi电脑间完成150MB双向直传、保存到手机及SHA256一致性验证；两台Android手机互传、锁屏持续传输仍待单独实测。详见 [局域网快传](docs/local-file-transfer.md)。普通服务器上传沿用3117的内存修复，但真实大文件发送失败尚未定位完成；不能把快传测试视作该问题已经解决。3118为此前本地验证记录，相关改动随3119预发布一并提供。

## 3117 修复（2026-10-29）

- 修复大 APK/普通文件发送时的整文件内存占用：选择后保留磁盘路径，发送时按 512KB 分块流式读取。
- APK、视频及普通附件不再尝试图片解码，保留累计上传进度及失败重试；重试使用新的上传任务。
- 使用 VC 现有分块接口，无需升级服务端。图片转换、相册相机和系统分享保持原有路径及限制。

已通过 150MB 文件分块与 SHA256 完整性测试，以及相关消息/分享/通知回归；真实服务端发送结果需实机确认。详见 [大文件上传](docs/large-file-uploads.md)。

## 3116 更新（2026-10-26）

- 通知设置提供 FCM 与后台消息通知两个联动开关，只能选择一种；上方“消息通知”总开关可停止提醒。
- 后台模式撤销 FCM 登记且不获取 Google 令牌；切回 FCM 后登记设备并关闭常驻消息连接。登录、注册完成后统一应用通知偏好。
- Firebase 初始化失败也能向 VC 撤销登记；VC 请求失败显示状态并重试。原生入口拒绝切换后已排队的本地通知。
- 延续 3115 的 VC 官方 Firebase 配置、设备登记与令牌轮换、失败重试、通知点击账号校验。VC 管理员 Firebase 选择“使用官方配置”，手机需具备 Google Play 服务及可用网络。

本轮 68 项相关 Flutter 测试、37 项 Android 原生测试及修改范围静态检查通过。已保留数据覆盖安装 3116；用户实测开关正常互斥，两种模式都只收到一次通知，点击均进入正确聊天。FCM 与后台连接没有双通道兜底；切换前已进入投递的推送不能追溯撤回。详见 [通知模式与去重边界](docs/android-notification-deduplication.md)。

## 3114–3115 新增功能

- 按账号、会话自动保存文字草稿和提及用户；会话列表显示草稿。待发送附件和引用暂不跨重启保存。
- Android 系统分享接入文字、链接、图片、视频和文件，选会话后进入待发送区，由用户确认发送。
- 聊天记录搜索支持会话、发送人、日期、文字/图片/视频/文件筛选，保留历史翻页、定位高亮和返回结果。
- 收藏表情管理页支持拖动排序，顺序按账号保存在本机，不增加分类。
- 正式版接入官方 FCM 推送，并提供设备登记状态及重试入口；不包含通知栏直接回复。

3114 完整客户端回归 662 项通过、5 项环境用例跳过；3115 完整回归 670 项通过、5 项环境用例跳过，之后增加通知界面和登记诊断测试。FCM 后台送达及点击跳转已实机核对；3116 的单独验证结果见上方。

## 3113 更新

- 修复聊天列表右上角“+ → 联系人”入口，打开独立查找页面，支持名字、账号邮箱和用户 ID 查询，点击结果进入会话。
- “+ → 搜索”打开独立聊天记录页面，搜索文字及 Markdown 消息正文；可继续搜索更早记录，点击结果跳转并高亮对应消息。
- 查询切换、清空或切换账号时取消旧请求；网络失败可重试，已有本地结果仍可使用。
- 保留 3112 的启动动画和右下角列表加载提示。

3113 新增功能 13 项测试及相关静态检查通过。扩展回归 79 项通过，5 项既有相机/表情交互测试在原 3112 基线下同样失败。已在连接的 Android 手机上验证联系人查询、打开原会话、中英文消息搜索、结果定位高亮及返回保留结果；使用原签名保留数据覆盖升级，原登录状态及所检查的历史文字和图片正常显示。

## 3112 更新

- 移除本地恢复页进入首页时的额外缩放过渡，避免与 Android 系统打开动画叠加。
- 会话、联系人列表加载和后台刷新提示改为右下角灰色小字，完成后自动消失。
- 启动优先恢复本地账号，服务器身份和登录验证在后台完成，网络超时保留本地会话。

本次发布同时包含此前未发布到此仓库的 3107–3110 功能：个人收藏表情、多张图片/GIF 导入、分类记忆与同服务器收藏同步；相册混选图片和视频，拍照/录像后加入待发送区。

3112 已通过 27 项路由、冷启动和登录恢复测试、相关静态检查以及 ARM64 Release 构建。已在连接的 Android 手机上保留数据覆盖升级并录屏复测启动过渡；3111 已实机核对登录、原会话、历史文字与图片显示。收藏同步的真实账号跨设备业务链路尚未完成验证。

## 保留的功能

新版会话、表情与回应、RTC 通话、Avo、通话小窗、后台消息及来电通知；页面、设置和服务器账号面板沿用旧版风格。不启用应用内更新。

消息通知可选择 FCM 或后台连接，并允许系统聊天消息通知。后台连接模式另需允许相应电池及后台运行设置；FCM 需要 Google Play 服务及可用网络。通话和 Avo 需要服务器相应功能支持。

## 构建

环境：Flutter 3.35.7 / Dart 3.9.2、JDK 17、Android SDK 36、NDK 27.0.12077973。

按 [BUILD-LEGACY-UI.txt](BUILD-LEGACY-UI.txt) 配置 Android SDK 和签名后：

```sh
flutter pub get
flutter build apk --release --flavor standalone --target-platform android-arm64 --no-pub
flutter test --no-pub
```

签名私钥、密码、本机路径、测试账号和手机诊断记录不在仓库中。覆盖已安装的交付包需要沿用原签名。

上游商店发布和桌面构建工作流保留在 `docs/upstream-workflows/`，未在本仓库自动运行。
