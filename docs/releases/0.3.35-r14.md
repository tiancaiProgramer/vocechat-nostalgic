# vocechat怀旧版 0.3.35-r14（3135）

保留怀旧版页面风格，选择性同步官方 0.3.36～0.3.38 的六项更新。

## 更新内容

- 字号新增 140%，保留既有字号档位、设置持久化和系统字体支持。
- 自动删除新增一个月（30 天），有效期从发送时计算。
- 群主及管理员可在服务器支持时设置全群新消息的统一删除期限。个人设置可以更短，实际取较短期限。界面先检查服务端支持情况。
- 自动删除消息显示小钟图标，点击查看剩余时间，去掉整块消息底色。
- 修改密码后及时退出失效会话并提示重新登录。收到会话终止事件后停止重连，WebSocket 和 HTTP SSE 的 401 响应可触发会话重新验证。
- 清空聊天记录后同步更新聊天内容、会话预览和本地缓存，离线恢复后核对服务器历史。按删除边界处理，保留待发送消息及上传任务。
- 增加表情同步失败的错误类型、HTTP 状态和已知服务错误码诊断，便于区分容器上游连通问题。

## 收藏表情 Docker 部署

新增独立附件 `vocechat-stickers-docker.zip`。

- 自动识别 VC 与 NPM 现有共享网络，优先复用 `nas-services`。
- 表情服务通过 Compose 固定接入，容器重建后自动恢复连接。
- 旧部署的 `.env` 可补充网络设置，沿用已有服务器地址及收藏数据。
- `sh check.sh` 同时检查服务健康和 VC 校验接口连通性。
- VC 内部地址可通过 `.env` 的 `VC_UPSTREAM` 设置。

部署步骤见 [Docker 部署说明](../../tool/sticker_server/README.md)。

## 已验证

- Flutter 完整回归 857 项通过，5 项条件用例跳过。
- 自定义功能专项 512 项通过，3 项条件用例跳过。与完整回归用例有重叠。
- 本地性能基准对照 r13，消息解析及缓存读写耗时接近。200 个会话的后台历史核对新增约 1.3 MB 模拟响应数据、最多 3 路并发，缓存列表先显示。
- 原签名 ARM64 Release 已保留数据覆盖安装到小米 MIX Fold 3，核对原有账号、聊天历史、系统字体和本机收藏保留。
- 实机同步失败日志曾显示 `502 / vc_unavailable`，确认 VC 与表情容器网络分离。用户手动加入共同网络后确认云朵打勾。
- 表情服务、准备脚本及检查脚本共 27 项本地测试通过，覆盖账号隔离、原图校验、配额、网络识别、旧部署迁移及健康检查正常但上游失败的场景。
- 应用 `lib/` 与 `test/` 静态检查无错误，原有 `server_store.dart` 的 JsonKey 注解警告仍存在。

## 尚未实测与边界

- 新的跨设备密码撤销、历史清空和群聊统一删除，需要在支持相应功能的服务器上继续验证。30 天到期使用本地模拟测试。
- 本轮没有重新完成真实通话、FCM 送达、跨手机快传或相机/媒体发送的全部端到端测试。FCM 实机日志曾提示 Google 服务不可用。
- 新精简部署包尚未在飞牛上整包重新部署验证。准备脚本使用模拟 Docker 命令测试，检查脚本及表情服务使用真实本机 HTTP 测试服务。
- 本地测试进程耗时不能代替手机帧率、长期内存、待机耗电测量。实机启动采样受其他手机操作影响，未作为可靠的前后性能结论。
- r13 及此前说明中的其他未验证范围继续适用。
