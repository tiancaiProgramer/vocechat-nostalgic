# 0.3.35-r10（3131，本地验证版）

在“设置 → 外观和语言”新增字体选择：

- 跟随系统字体（默认）：Android 使用系统提供的 sans-serif 字体族及字形回退，其他平台使用对应平台字体。
- 应用默认字体：继续使用怀旧版内置 Inter 和既有中日韩文字、表情回退。
- 切换立即生效并自动保存，聊天正文、标题、按钮、输入框、文字头像及弹窗同步切换；保留原有字号设置及系统字号缩放。
- 图标字体保持独立，收藏表情、图片、视频及传输功能不变。

手机主题商店安装的字体是否能被读取取决于厂商系统的字体配置，尚未完成更换系统字体的实机对照，不能保证所有厂商字体都生效。

本地验证：97项字体、设置、聊天排版与更新相关测试通过，覆盖立即生效、重启恢复、快速切换的保存顺序、存储失败重试、130%窄屏与深色排版、Apple平台字体，以及保留字号。新增字体相关代码静态检查无问题。

包含r9全部功能。r9的“检查更新”已由用户在手机确认显示当前版本无需更新。

本版本未提交或推送GitHub，未创建Release。

后续实机发现r10仅切换通用字体名称，未读取小米主题字体；r11已改用原生实际字体文件加载并由用户确认换字体生效。
