# 0.3.35-r8（3129，本地测试版）

保留怀旧版界面和现有功能，选择性同步官方 0.3.35 功能与必要重连修复。

- A：在“外观和语言”中增加字号调整，支持85%～130%、实时预览、保存及恢复默认；默认100%，保留系统字体缩放。
- B：遵循服务器邮箱隐藏设置，同步清理展示资料及缓存；展示邮箱与已保存登录凭据分开处理。
- C：邮箱为空时显示UID，机器人分组优先依据服务端 `is_bot`，保留昵称、邮箱和UID搜索。
- D：新建空群立即出现在会话列表，防止旧刷新响应覆盖；安卓折叠屏保留怀旧单页导航。
- E：优化左右消息布局的文字换行和头像留白；保留原有媒体缩略图尺寸策略。
- 聊天昵称采用青蓝色，正文保持灰色；浅色和深色均作区分。
- 修复断线期间发送消息推进接收游标而漏收旧消息的问题；接收消息与游标在同一事务落盘，重连时补齐当前聊天历史。
- Wi-Fi与移动网络直接切换时及时重连，保留现有WebSocket/HTTP SSE兼容、消息顺序与在线状态处理。
- 保留现有FCM登记重试、后台通知互斥和通知点击定位，不导入另一套推送实现。
- 包含r7的下载进度、保存阶段和保存位置提示。
