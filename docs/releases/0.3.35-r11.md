# vocechat怀旧版 0.3.35-r11（3132）

保留怀旧版界面和现有功能，汇总此前未单独发布的r7～r10更新，并修复系统主题字体跟随。

## 更新内容

- “设置 → 外观和语言”增加“跟随系统字体 / 应用默认字体”，默认跟随系统；支持85%～130%字号调节、实时预览、自动保存和恢复默认，保留系统字号缩放。
- Android 12及以上通过原生文字排版接口确定实际使用的字体，把对应字体数据加载到Flutter。返回前台或重新选择系统字体时检查变化，无需手动重启；保留中日韩字形及系统回退。读取或解析失败时回退并给出提示，不增加启动等待页。
- 设置中的“关于”增加官网、怀旧版GitHub项目、反馈问题及手动检查更新。只读取本仓库正式发行版，按Android构建号判断升级，避免降级；Android独立分发版可下载适用ARM64 APK并交给系统安装器处理。
- 同步官方0.3.35选定功能：遵循服务器邮箱隐藏设置；无邮箱用户显示UID；机器人分组优先使用服务端标记；新建空群及时出现在会话列表。保留昵称、邮箱和UID搜索。
- 聊天昵称采用青蓝色，与正文区分；优化消息换行及头像留白，保留现有媒体缩略图策略。
- 修复断线期间发送消息可能推进接收游标、导致漏收旧消息的问题；消息与接收游标同时落盘，重连补齐当前聊天历史；改进Wi-Fi与移动网络直接切换时的重连。
- 聊天文件下载立即显示进度、保存阶段、完成勾和保存位置；失败可重试，下载期间避免重复点击。保持现有上传接口及文件消息格式。
- 保留既有收藏表情、混合相册、实况照片、局域网文件传输、系统分享、草稿、搜索、FCM/后台通知互斥及通话功能。

## 验证结果

- 全量Flutter回归：809项通过，5项条件用例跳过；另2项Android原生字体桥测试通过。
- 系统字体相关静态检查无问题；原签名ARM64正式包，应用ID保持`com.privoce.vocechatclient.legacyui`。
- 已覆盖安装到小米2308CPXD0C（Android 16），保留原数据。用户更换系统字体后确认应用文字同步变化；同一进程的日志确认从MiSans切换至主题字体，昵称、正文和输入提示均跟随。
- 已实机核对130%字号及重启保存、聊天昵称颜色、断网恢复Wi-Fi后当前聊天实时收消息，以及关于页面手动检查更新。
- 聊天APK文件在发送端完成下载并与服务器SHA-256一致，网页端也已完成同文件下载。
- APK完整性、原签名及16KiB ZIP对齐检查通过。

## 未验证范围与限制

- 其他厂商及旧版Android的主题字体未实机验证；Android 12以前仅保留旧MIUI主题文件读取回退。
- 手机没有可用移动数据，Wi-Fi与可用移动网络的直接切换只有本地模拟覆盖；真实服务器邮箱隐藏开关变化未做实机联测。
- 官方Android 0.3.33接收端下载未实机验证，不能承诺其下载问题已解决。
- 应用内新版APK下载、系统安装器确认到覆盖升级的完整新包升级流程，尚未实机走通；已覆盖版本判断、链接校验和安装器的本地测试。
- 此次仅交付Android ARM64包；iOS和其他平台没有新增实机验证，历史版本说明中的未验证项目仍适用。
