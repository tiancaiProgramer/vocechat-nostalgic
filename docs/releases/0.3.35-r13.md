# vocechat怀旧版 0.3.35-r13（3134）

修复后台消息模式在手机重启、应用更新后无法自动恢复，以及服务已启动但对端仍显示离线、锁屏收不到消息的问题。包含此前未单独发布的r12改动。

## 更新内容

- 增加开机完成、应用更新后的后台恢复入口；在用户已解锁、后台消息模式开启且已有登录会话时恢复服务。
- 后台服务支持系统重建及空启动指令，先建立前台服务，再恢复消息运行环境；打开界面时复用同一引擎与会话。
- 将应用数据状态的调度与界面绘制分离。没有界面窗口时，登录恢复、消息订阅和重连也能推进，避免只启动服务却没有建立有效消息会话。
- 关闭后台消息模式、切换FCM或退出登录后不自动恢复后台常驻；开机恢复不会启动麦克风或恢复旧通话。
- 增加仅记录连接阶段的诊断，便于区分服务启动、有效会话与聊天事件，不记录账号、凭据或消息正文。
- 保留r11的字体/字号、关于及检查更新、聊天布局、下载进度，以及原有表情、媒体、文件传输、通知模式和通话功能。

## 已验证

- 本次38项相关Flutter测试通过、2项渠道条件用例跳过；26项Android通知和恢复测试通过，变更相关静态检查无问题。
- 无界面帧的对照测试复现旧方式的数据更新停滞，新方式能继续建立订阅；打开界面不重复初始化，资源退出可正常释放。
- 已用原签名保留数据覆盖安装到小米2308CPXD0C（Android 16）。未打开应用，由应用更新广播恢复后收到服务端ready与聊天事件；用户确认另一客户端显示在线，锁屏收到一次新通知。
- 用户再次真实重启、解锁后未打开应用，再锁屏发送新消息，确认对端显示在线、收到一次通知。原生日志记录BOOT_COMPLETED → 后台运行环境启动 → ready → chat。
- APK版本、原签名、ZIP完整性及16KiB ZIP对齐检查通过。

## 尚未实测与边界

- 多小时或整夜待机、真实系统回收进程后的恢复尚未完成实测；恢复策略及空启动指令已有本地用例覆盖，不能等同于这些实机场景已通过。
- 其他厂商、其他Android版本的开机与后台行为未实机验证；手机厂商的自启动、后台运行设置仍需允许应用运行。
- 系统设置中的“强行停止”会阻止应用自动恢复，之后需手动打开；本修复不绕过该用户操作。
- r11及此前说明中的其他未验证项目仍适用；本轮没有重新做全功能实机回归。
