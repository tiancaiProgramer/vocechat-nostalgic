# 0.3.33-r6：分类接收目录与紧凑传输界面

2026-10-30 预发布。Android 内部构建号 **3127**，沿用原应用 ID 和签名，支持 Android 7.0 及以上 ARM64，可覆盖升级并保留应用数据。包含自 GitHub r1 之后的 r2～r6 本地更新。

- 传输页右上角新增“接收设置”，图片和其他文件可分别选择目录，按账号保存持久授权。未设置时仍使用应用内目录，只影响新接收文件。
- 接收完整校验后自动移动到对应目录，再校验目标内容后删除应用内原件。同名文件加序号；目录不可用时保留原件并提示。
- 接收列表显示实际位置，重新进入仍保留自定义目录记录；“另存”也可移动已存入自定义目录的文件。
- 本机信息改为摘要，待发送文件和附近设备合并为一个区域，接收记录默认折叠，设置收进右上角。
- Android 系统分享保持一个 Vocechat 入口，应用内可选择聊天或文件传输；普通文件、视频和磁盘图片按路径处理，移除旧 32 MiB 单文件、64 MiB 总量限制。
- 文件传输成功后自动移除已发送文件，失败或未发送项保留重试；回形针入口改为“互传”，主页菜单和页面标题仍为“文件传输”。

## 验证

- 13 项 Android 测试通过：分类路由、账号隔离、同名保留、空文件、目录失效、重启记录、中断恢复、另存移动和原件保护。
- 14 项传输测试通过，包括 150 MiB、SHA-256 完整性、拒绝、取消和自动保存失败回退。相关 Dart 静态检查通过。
- Android 16 手机上分别接收 69 字节 PNG 和 1,048,593 字节普通文件，进入两个不同目录，实际落盘 SHA-256 与来源一致。
- 重启后两个目录设置、授权及记录保留；再次另存 PNG 成功，原目录文件消失，目标内容一致。
- 临时目录及合成文件已清理，两个类别恢复为默认应用内存储，供用户自行选择正式目录。原有文件保持原位。
- 最终 ARM64 Release、原签名、版本、ZIP 完整性及 16 KiB ZIP 对齐检查通过；已覆盖安装 r6/3127，首次安装时间保留。连接手机横屏下，本机摘要、合并发送区和折叠接收区可完整显示在一屏。

## 使用及验证范围

从文件传输页右上角齿轮进入“接收设置”，图片和其他文件可分别选择具体子目录，仅影响新接收文件。目录授权失效后需重新选择；Android 系统会限制部分根目录。

- r2 阶段已通过 80 MiB 外部分享进入聊天和传输待发送区的手机验证；没有自动发送聊天消息。分享仍最多16个文件，并有 1 TiB 合理性边界；HEIC 转换保留独立的 64 MiB 解码保护限制。
- 两台安卓手机互传、锁屏/后台持续传输及完整断网场景尚未在本轮实测。此前手机到电脑测试端的 TCP 超时问题未确认解决。
- 普通 VC 服务器真实大文件上传此前失败的问题尚未确认解决。本轮没有发送 VC 聊天测试消息，也没有重新验证真实通话及全部媒体编码链路。
- 三项旧相机/混合相册 Windows 测试在 r1 与本轮代码中均失败，未计入通过项；本轮没有重新运行整个客户端全量套件。
- 局域网传输采用 `vocechat-lan-1`，与快图 QuickPic 的快传不互通。其他边界沿用 [r5](0.3.33-r5.md) 和此前说明。

发布附件包含原签名 APK、对应提交的源码 ZIP、中文更新说明和 SHA-256 校验文件；签名私钥、密码、本机配置和手机诊断记录不随发布上传。
