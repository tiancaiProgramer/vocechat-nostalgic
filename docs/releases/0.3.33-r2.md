# 0.3.33-r2：文件分享与待发送区

Android 内部构建号 **3123**，本地交付版本，沿用应用 ID 和原签名。

## 更新

- 文件传输成功后，已发送文件自动移出待发送区；失败或未发送文件保留。
- Android 系统分享只有一个 Vocechat 入口。进入后可选择“文件传输”，文件自动加入待发送区；也可继续选择聊天会话。
- 文件、视频和磁盘图片统一按路径暂存与分块上传，取消系统分享的 32 MiB 单文件和 64 MiB 总量限制。保留最多16个文件及必要的磁盘空间要求。
- 回形针面板入口改为“互传”；聊天主页“+”菜单和传输页面仍叫“文件传输”。

## 验证与边界

- 50 项相关 Flutter 测试、4 项 Android 原生分享测试及修改范围静态检查通过。覆盖 80 MiB 分享、150 MiB 分块上传与局域网传输、发送队列清理、失败重试和分享取消。
- ARM64 Release 构建、原签名、版本号、非 debug 属性、ZIP 完整性及 16 KiB ZIP 对齐检查通过。
- 已在连接的 Android 16 手机上保留数据覆盖安装，版本名 `0.3.33-r2`、构建号 `3123`，首次安装时间保持不变；原账号、会话及所查看的历史图片仍可访问。
- 实机合成 80 MiB 文件分别经外部分享加入传输和聊天待发送区，选择目标前不读取文件主体；已核对“互传”及“文件传输”标签，并移除测试草稿和临时测试助手。本轮没有发送 VC 聊天消息。
- 三项旧相机/混合相册 Windows 测试在本轮与原 r1 代码中均失败，未计入上述通过项。
- 普通服务器大文件实际发送、两台安卓手机互传及锁屏持续传输尚未在本轮完成验证；此前手机到电脑测试端 TCP 超时问题未确认解决。
- 本功能采用 `vocechat-lan-1` 协议，与快图 QuickPic 的快传不兼容。HEIC 转换仍有独立的 64 MiB 解码保护限制。
