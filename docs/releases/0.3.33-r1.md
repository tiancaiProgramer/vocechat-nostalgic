# 0.3.33-r1：输入栏对齐、菜单排序和版本命名

Android 内部构建号为 **3122**，基于 3119，包含此前本地交付的 3120、3121 调整。沿用预发布状态，已知限制仍保留。

## 更新

- 聊天输入栏的表情、回形针和语音图标按可见轮廓高度对齐；回形针倾斜 25 度，语音图标微调大小和垂直位置。
- 聊天列表右上角“+”菜单改为 **文件传输 → 新建聊天 → 联系人 → 搜索**，其余选项的相对顺序保持一致。
- 对外显示版本为 **0.3.33-r1**，后续交付依次使用 `-r2`、`-r3`。内部构建号继续递增，规则见[版本命名](../versioning.md)。
- 包含 3119 的紧凑媒体、实况照片及局域网快传功能，详见[3119 发布说明](3119.md)。

## 验证

- 本次相关静态检查、Android ARM64 Release 构建通过。APK 原签名、包名、版本、非 debug 属性、ZIP 完整性及 16 KiB ZIP 对齐检查通过。
- 3120 已在手机测量三枚图标的可见上下边缘，差不超过 1 个屏幕像素；表情与附件入口正常。3121 已核对四项菜单顺序及文件传输入口。
- r1 只继续调整版本名和构建号，已在连接手机上保留数据覆盖安装；实际版本名为 `0.3.33-r1`、构建号 `3122`，首次安装时间保留。
- 此前 3119 实机检查通过：原登录与所检查的历史文字/图片、冷启动、本地草稿恢复、联系人查询、聊天正文搜索、搜索结果跳转和图片类型筛选。
- 已使用原会话中一张真实安卓 HEVC 动态照片核对预览、重播及声音开关，并通过录屏观察到实际视频画面变化；没有做音频听感验证。
- 电脑和手机能够相互发现；电脑到手机的 **1,048,593 字节合成文件**接收、保存及实际落盘 SHA-256 校验通过，传输结束后专用前台服务退出。
- 3119 发布时记录的自动回归为 713 项通过、5 项环境用例跳过。本次 UI/版本变更未重新运行该全量套件。

## 已知问题与未验证范围

- **手机到电脑快传未通过**：手机到临时电脑接收端的 TCP 连接超时；电脑本机可连接其监听端口。反向网络连通性仍需排查防火墙、VPN 或路由设置，不能宣称双向快传正常，也不能据此直接认定客户端代码有错。
- 尚未完成两台安卓手机互传、锁屏/后台持续传输和断网场景的实机验证。本轮 1 MB 测试不代表 150 MB 负载已在 r1 复测。
- 动态照片验证限于一张真实安卓素材的预览，不代表 iPhone 配套素材导入、HEIC 转换、全部视频编码及“导入→发送→接收”链路均已通过。
- 本轮未发送任何 VC 聊天测试消息，未测试普通服务器大文件上传、真实通话或真实账号跨设备收藏同步。此前普通大文件上传失败问题仍未确认解决。
- 其他功能和格式边界沿用 [3119 说明](3119.md)。

## 下载与升级

Android 7.0 及以上、ARM64。包名和原签名一致，可覆盖安装既有怀旧版，保留应用数据。

附件包括原签名 APK、当前提交的源码 ZIP、中文更新说明和 SHA-256 校验文件。签名私钥、密码、本机配置及手机截图/诊断记录不随发布上传。
