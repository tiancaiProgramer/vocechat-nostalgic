# 版本命名

从本次交付开始，对外版本在基础版本末尾添加 `-rN`，从 `-r1` 开始，后续交付依次为 `-r2`、`-r3`。

当前版本：

- 对外显示和 Android `versionName`：`0.3.33-r1`。
- 内部 Android `versionCode`：`3122`，继续沿用单调递增的构建号，以支持原签名覆盖升级。
- Flutter `pubspec.yaml`：`version: 0.3.33-r1+3122`。
- APK 文件名：`vocechat怀旧版-0.3.33-r1-arm64.apk`。

下一次交付示例：`0.3.33-r2+3123`。对外说明以 `0.3.33-r2` 为版本名称，内部构建号用于升级识别。

签名和应用 ID 延续原设置。`r1` 包含此前 3120 的输入栏图标对齐、3121 的加号菜单排序，以及 3119 底座；更改版本名称不代表此前尚未验证的功能或已知网络问题已经解决。
